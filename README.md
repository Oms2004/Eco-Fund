🌍 EmpowerAid – NGO Crowdfunding Platform

EmpowerAid is a full-stack web application designed to bridge the gap between donors and NGOs by providing a transparent, secure, and user-friendly crowdfunding platform. It enables individuals to discover verified NGOs, contribute to meaningful causes, and track the impact of their donations.

🚀 Features

👤 User Features
User Registration & Login (Authentication)
Browse NGOs by category and location
View NGO details, campaigns, and impact
Donate securely to NGOs or specific campaigns
Track donation history
Rate and review NGOs


🏢 NGO Features
NGO Registration & Profile Management
Create and manage fundraising campaigns
Track donations and supporters
Upload updates and reports
⭐ Additional Features
Area-wise NGO listing
Search and filter functionality
Real-time donation tracking
Transparent fund allocation system
